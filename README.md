## 🚀 How to Run & Preview Locally

### Option 1: Direct Browser Launch (Zero Dependencies)
Simply double-click `index.html` in your file explorer, or right-click `index.html` &rarr; **Open with Chrome / Edge / Firefox**.

### Option 2: Local HTTP Server (Node.js)
```bash
# In the portfolio directory:
npx serve .
# Open http://localhost:3000
```

## 🌐 1-Click Free Deployment

### Deploy to GitHub Pages:
1. Push this folder to a GitHub repository (e.g. `github.com/ajay2805/portfolio`).
2. Go to **Settings** &rarr; **Pages**.
3. Under **Build and deployment**, select **Source: Deploy from a branch** &rarr; `main` / `/ (root)`.
4. Your site will be live at `https://ajay2805.github.io/portfolio`!

### Deploy to Vercel or Netlify:
- Drag and drop this folder directly into [Vercel](https://vercel.com) or [Netlify Drop](https://app.netlify.com/drop).
- Live in under 15 seconds with global CDN and automatic SSL!
